    GitHub 设置

    上传功能通过 GitHub API 提交文件，GitHub Actions 会自动构建并发布，无需命令行。 需要一个有仓库写权限的 Token（只存在这台电脑的浏览器里）。

    GitHub 用户名
    仓库名
    分支
    Personal Access Token

    怎么创建 Token：

    1. 打开 github.com/settings/personal-access-tokens/new（细粒度 Token）
    2. Repository access 选 Only select repositories → 只勾这个博客仓库
    3. Permissions → Repository permissions → Contents 设为 Read and write
    4. Expiration 选一个较短的有效期，生成后复制过来

    Token 保存在浏览器的 localStorage 中，仅本机可见。若担心安全，用完后去 GitHub 撤销即可。
